# SecureAI HR Assistant

SecureAI HR Assistant is a Django-based HR chatbot
with security features for detecting suspicious prompts,
protecting sensitive information, and validating responses.

## Features

- HR Chatbot
- Prompt Injection Detection
- Sensitive Data Masking
- AI Response Validation
- Security Audit Logs
- Security Dashboard
- Login and Logout Protection

## Technologies Used

- Python
- Django
- SQLite
- HTML
- Git and GitHub

## Project Purpose

The project combines HR assistance with basic AI security
practices to help protect sensitive employee information.

## Future Enhancements

- Role-based access control
- Advanced AI integration
- Improved security monitoring
- Employee authentication
